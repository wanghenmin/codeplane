1.Project OverviewIn class, we have worked with text datasets with labels for supervised learn-
ing based binary classification, and unsupervised learning techniques. But what about semi-
supervised learning tasks? Semi-supervised learning is a machine learning paradigm in which
a model is trained on a dataset that contains both labeled and unlabeled examples. In this project,
you will investigate semi-supervised learning techniques applied to the multi-label task of pre-
dicting five clinical-trial stopping reasons (Safety, Funding, Efficacy, Recruitment, and Other) with
partially missing reason labels. Each reason label is binary (0 or 1), and a trial may have more than
one reason label equal to 1. Other includes other or unspecified stopping reasons. This is com-
mon in the real world, where data acquisition devices/sensors fail, or human annotators are too
expensive/inaccessible. This project will therefore consist of two parts:
(a) Part 1: Use at least one unsupervised learning method (optionally combined with supervised
learning techniques) to automate the addition of labels to the data examples with missing

lect a model and combinations of features using validation performance onpart1_val.csv,

I, II, and III), analyze its prediction errors across reason categories using the reason labels

• A trial may have several matched drugs (separated by semicolons indrug_smiles) or none,
so you need to decide how to combine fingerprints across drugs and how to handle trials

import numpy as np
import pandas as pd
from rdkit import Chem, DataStructs
from rdkit.Chem import Descriptors, rdFingerprintGenerator
gen = rdFingerprintGenerator.GetMorganGenerator(radius=2, fpSize=1024)
mol = Chem.MolFromSmiles("CN(C)C(=N)NC(N)=N") # metformin
fp = gen.GetFingerprintAsNumPy(mol) # 1024 bits; 17 are 1
print(Descriptors.MolWt(mol), Descriptors.MolLogP(mol)) # 129.17, -1.03
aspirin = Chem.MolFromSmiles("CC(=O)Oc1ccccc1C(=O)O")
print(DataStructs.TanimotoSimilarity(gen.GetFingerprint(mol),
gen.GetFingerprint(aspirin))) # 0.05
def trial_fingerprint(smiles_field):
"""Combine the fingerprints of all matched drugs in one trial."""
if pd.isna(smiles_field):
return np.zeros(1024) # no matched drug
fps = [gen.GetFingerprintAsNumPy(m)
for s in smiles_field.split(";")
if (m := Chem.MolFromSmiles(s)) is not None]
return np.max(fps, axis=0) if fps else np.zeros(1024)

The drug-knowledge features link each drug in thedrugscolumn to its molecular structure and to
the biological pathways it may affect. Drugs were matched by exact name to a DrugBank-derived
table of small-molecule drugs, so biologics (e.g., antibodies) and drugs listed under other names
are not matched; about 56% of Part 1 trials have at least one matched drug, and the drug columns
are empty for the rest. Each column lists values for all matched drugs of a trial, separated by semi-
colons:
•Matched drugs.matched_drugslists the drug names that were matched.
•Drug pathways.A drug does not act on a pathway directly: it binds one or more protein
targets(drug_targets, given as gene symbols), and each target participates in pathways cu-
rated by the Reactome database (drug_pathways, given as Reactome IDs;pathway_catalog.csv
maps eachreactome_idto itspathway_name,pathway_level, and the number of drugs and
targets in it). A pathway is a set of molecular reactions that together carry out a biological
function, such as “Hemostasis” (blood clotting) or “Signaling by GPCR.” A drug’ s pathways
are therefore the union of the pathways of all its targets. The columndrug_actionsde-
scribes how the drug affects its targets (e.g., inhibitor, agonist); actions are pooled across all
targets of the trial’ s matched drugs, so the link between a specific action and a specific target
is not available.
•Pathway level.Reactome organizes pathways as a hierarchy.pathway_level(inpathway_
catalog.csv) is a pathway’ s depth in that hierarchy: level 0 contains the 29 broadest cate-
gories (e.g., “Signal Transduction,” “Metabolism,” “Immune System”), and higher levels are
increasingly specific sub-pathways (the deepest is level 9). For example, “Formation of Fib-
rin Clot” (level 1) is part of “Hemostasis” (level 0) and contains “Intrinsic Pathway of Fibrin
Clot Formation” (level 2). A target that belongs to a specific pathway is also listed under every
broader pathway that contains it.pathway_leveldescribes the pathway, not the drug, and
is an ordinal depth rather than a measured quantity.
